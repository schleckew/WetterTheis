Automatische Aktualisierung (GitHub-Zugang)
  1. Auf github.com: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Bei „Repository access“ nur dieses Repository wählen. Unter „Permissions → Repository permissions“ bei Actions auf Read and write stellen. Ablauf: so lang wie möglich.
  3. Token kopieren und hier einfügen. Er wird nur in diesem Browser gespeichert, auf Handy und PC also jeweils einmal eingeben.
